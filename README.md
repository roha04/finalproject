# Прогноз енергоспоживання навчального корпусу та вибір енергозберігаючих заходів

Фінальний проєкт курсу «Економіко-екологічні задачі»: від підготовки місячного ряду споживання до прогнозу на опалювальний сезон і багатокритерійного вибору портфеля заходів.

## Коротка постановка

На основі щомісячних даних про споживання електроенергії навчальним корпусом за **2022–2026** спрогнозувати споживання на **наступні 6 місяців** і вибрати набір енергоефективних заходів, що забезпечує компроміс між витратами та викидами CO₂ за бюджету **≤ 500 тис. грн**.

Повний опис блоків 1–8 — у [`REPORT.md`](REPORT.md) і на початку ноутбука.

## Що робить проєкт

| Контрольна точка | Зміст |
|------------------|--------|
| **КТ 1** | Синтетичний датасет, пропуски, аномалії, очищення, `co2_tons` / `cost_uah` |
| **КТ 2** | EDA (динаміка, scatter, кореляції) + Linear Regression / Random Forest |
| **КТ 3** | Часовий ряд: наївний сезонний baseline vs лінійна модель; прогноз 6 міс. (warm/base/cold) |
| **КТ 4** | Перебір заходів за бюджетом, мін. економією ≥15%, вагою екології; таблиця компромісів |

## Дані

Місячні спостереження: **січень 2022 — вересень 2026**.

| `co2_tons` | Оцінка викидів CO₂ (після очищення) |
| `cost_uah` | Вартість за тарифом 7.5 грн/кВт·год |

Датасет **синтетичний**, з реалістичною сезонністю. Для КТ 1 додано пропуски та аномалії.

## Моделі та метрики

**КТ 2** (train = усі місяці крім останніх 12, test = останні 12):

1. Базова лінійна регресія: лише `temperature_c`
2. Багатофакторна лінійна: температура, навчальні дні, опалення, світловий день
3. Random Forest (100 дерев)

Метрики: **MAE**, **RMSE**, **R²**.

**КТ 3** (горизонт 6 місяців):

- Наївний сезонний baseline: значення того ж місяця рік тому
- Лінійна модель: тренд `t` + середнє за місяцем + sin/cos сезонність
- Прогноз на жовтень 2026 — березень 2027: base / cold (+12%) / warm (−10%)

## Оптимізація (КТ 4)

Шість заходів (LED, ІТП, термостати, вікна, рекуператори, СЕС). Перебір комбінацій з умовою сумарної економії ≥ 15%.

```
score = (1 − eco_weight) · econ_norm + eco_weight · eco_norm
```

У ноутбуці також є **таблиця компромісів** (крайні ваги екології × сценарії погоди) і **чутливість до бюджету**.

Параметри для демонстрації на захисті:

```python
LIVE_BUDGET = 500000      # грн
LIVE_ECO_WEIGHT = 0.5     # 0 = лише економіка, 1 = лише CO₂
WEATHER_SCENARIO = 'base' # 'warm' | 'base' | 'cold'
```
